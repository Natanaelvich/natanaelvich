# Natanael Silva Lima

**Full Stack Tech Lead no Grupo Abril** · React Native, Node.js e TypeScript · agentes de IA

Sou Full Stack Tech Lead no Grupo Abril desde outubro de 2023, trabalhando de forma remota a partir de Timbiras, no Maranhão. No dia a dia lidero o desenvolvimento com React Native, Node.js e TypeScript.

Também sou fundador da Solunorde, onde publico apps próprios. Hoje são 6 na App Store e 4 na Google Play, e eu cuido de tudo: produto, código, publicação e suporte.

## Como trabalho

- **CI/CD com publicação automática nas lojas**, usando Codemagic e Fastlane.
- **Testes E2E** para validar os fluxos principais antes de publicar.
- **Agentes de IA** com LangGraph, RAG e MCP, ligados a dados e ferramentas reais do produto.
- **Claude Code e Cursor no dia a dia**, para escrever, revisar e refatorar código.
